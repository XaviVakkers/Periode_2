Wat is het verschil met de script tag boven in te laden in de head tag t.o.v onder inladen aan het einde van je HTML tag

JavaScript wordt uitgevoerd voordat de HTML volledig is ingeladen. Eerst wordt de HTML ingeladen en daarna JavaScript uitgevoerd.

Wat doet de attribuut “defer” in de script tag

defer zorgt ervoor dat JavaScript op de achtergrond wordt geladen en pas wordt uitgevoerd als de HTML volledig is ingeladen.

Wat is het verschil tussen HTML en JavaScript?

HTML bepaalt de structuur van een website en Javascript zorgt voor interactie en functionaliteit

Wat is het verschil tussen innerHTML en innerText

innerHTML voegt HTML-code toe of past deze aan en innerText voegt gewone tekst toe of past deze aan.
